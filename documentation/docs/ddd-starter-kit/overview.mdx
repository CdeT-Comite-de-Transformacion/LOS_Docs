The [modkit starter kit](https://github.com/CdeT-Comite-de-Transformacion/LOS_Docs/blob/main/starter-kit/README.md) generates Go projects and modular DDD packages from embedded templates. See the [build and release guide](https://github.com/CdeT-Comite-de-Transformacion/LOS_Docs/blob/main/starter-kit/RELEASES.md) for Windows, Linux, and macOS binaries, Semantic Versioning tags, and automated GitHub Releases.
