# Language

The whole project (source code, comments, commits, documentation and variable names) must be written **exclusively in English**.

* **Comments and documentation:** `// Fetch user data from the database`
* **Commit messages:** `git commit -m "feat: add user authentication"`
* **Variable and function names:** `const userList = []`, `func getUserById()`

> **Note:** Avoid Spanish or Spanglish anywhere in the project's code.
