# Git-flow

![Git-flow diagram](/img/gitflow.svg)

## Protected branches

Only the authors **Viviana**, **Carlos** and **Cristian** can `push` directly to the `main` and `develop` branches. No other team member should publish changes to these branches.

## Pull Requests

Changes are integrated only through Pull Requests. Only PRs coming from the following branches are accepted:

- **feature:** new features, for example `feature/new-window`
- **bugfix:** bug fixes, for example `bugfix/error-login`
- **hotfix:** urgent fixes, for example `hotfix/payment-timeout`

> **Note:** Branch names follow the `kebab-case` convention described in [Naming Conventions](./naming.mdx) and must be written in English.
