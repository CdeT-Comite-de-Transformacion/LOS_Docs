# Naming Conventions

To keep the whole project consistent and readable, all naming conventions follow these structures:

#### kebab-case

* **Files and folders:** `component`,`user-component.js`, `main-styles.css`, `main.go`
* **Routes / URLs:** `/user-profile`, `/api/v1/user-profile`
* **CSS classes and selectors:** `.main-button`, `.card-container`
* **Git branches:** `feature/new-window`, `bugfix/error-login`

#### PascalCase

* **Classes:** `NewClass()`
* **Interfaces:** `NewInterface()`

#### camelCase

* **Methods and functions:** `getUserById()`, `calculateTotal()`
* **Variables and parameters:** `let userList = []`, `var totalAmount = 10`
* **Object / JSON properties:** `{ "firstName": "John", "isActive": true }`

#### snake_case

* **Databases:** `app_db`, `metrics_prod`
* **Tables:** `users`, `user_profiles`, `order_items`
* **Fields / Columns:** `id`, `user_id`, `first_name`, `created_at`, `is_active`

> [Go naming conventions guide](https://www.alexedwards.net/blog/go-naming-conventions)
