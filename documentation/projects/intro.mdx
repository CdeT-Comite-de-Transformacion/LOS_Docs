# LOS

**LOS (Lean Origination System)** is the origination system of the Transformation Committee. It manages the origination process end to end through backend services (BFF), process flows (BPM), document processing with OCR, centralized authentication and event messaging, deployed on AWS.

## Sections

- **Frontend:** the user-facing applications of LOS.
- **Backend:** the services that power LOS.
